# Brief Client Reformulé - Projet smartEngine

## 1. Description du Projet
RavenStack, une entreprise SaaS B2B proposant une plateforme de gestion de projets, fait face à un taux d'attrition clients (churn) impactant son revenu mensuel récurrent (MRR). Le projet **smartEngine** vise à concevoir un système de prédiction qui permettra de scorez la probabilité de résiliation des comptes clients.

## 2. Objectifs Métier
- **Anticipation** : Identifier les signaux comportementaux (usage des fonctionnalités, tickets de support) précurseurs du churn.
- **Actionnabilité** : Fournir aux équipes **Customer Success** un dashboard interactif pour prioriser les interventions sur les comptes à risque.
- **Automatisation** : Alerter automatiquement les responsables sur les comptes présentant un score de risque élevé.

## 3. Critères de Succès
1. **Réduction du taux de Churn** : Diminution de 15% du taux d'attrition global sur les 6 mois suivant le déploiement.
2. **Précision du Modèle** : Atteindre un score F1 (F1-score) de 0.80 minimum pour la détection des résiliations.
3. **Adoption Utilisateur** : Utilisation du dashboard par 100% des équipes Customer Success pour la gestion hebdomadaire de leurs comptes.

## 4. Contexte du Marché (SaaS B2B)
- **Modèle Économique** : Basé sur l'abonnement mensuel ou annuel. La **rétention** est plus critique que l'acquisition car le coût d'acquisition client (CAC) est souvent amorti sur plusieurs mois.
- **Rôle du Customer Success** : Garantir que le client tire le maximum de valeur du produit pour assurer le renouvellement de l'abonnement.
- **Métriques Clés** : MRR (Monthly Recurring Revenue), LTV (Lifetime Value), Churn Rate (Logo churn et Revenue churn).
